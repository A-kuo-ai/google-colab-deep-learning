# google-colab-deep-learning
# Google Colab 零成本完轉深度學習

## 一、專案介紹

本專案以 Google Colab 為主要開發環境，透過雲端運算資源進行 Python 程式設計與深度學習相關實作。Google Colab 提供線上程式執行環境，使用者不需要在自己的電腦安裝完整的開發環境，即可撰寫、執行及測試程式。

本專案將課程中的實作內容整理成 Jupyter Notebook（`.ipynb`）格式，並上傳至 GitHub，作為程式碼保存、學習紀錄與成果展示的地方。

## 二、專案目標

1. 熟悉 Google Colab 的操作方式與基本功能。
2. 學習使用 Python 進行程式設計與資料處理。
3. 認識深度學習的基本概念及實作流程。
4. 練習將 Google Colab 筆記本上傳至 GitHub。
5. 建立個人程式學習紀錄，方便日後查閱、修改與分享。

## 三、使用工具

| 工具 | 用途 |
|---|---|
| Google Colab | 撰寫及執行 Python 程式 |
| Python | 主要程式設計語言 |
| Jupyter Notebook（IPYNB） | 保存程式碼、文字說明及執行結果 |
| GitHub | 儲存、管理及分享專案檔案 |

## 四、專案內容

本專案主要記錄使用 Google Colab 進行課程實作的過程，並將完成的程式筆記本上傳至 GitHub。

目前的專案內容包含：

- Google Colab 雲端程式開發環境的使用。
- Python 程式碼撰寫與執行。
- 深度學習相關課程實作與學習紀錄。
- IPYNB 筆記本的下載、整理及上傳。
- GitHub Repository 的建立與管理。

實際實作項目將依照課程內容持續更新。

## 五、如何使用本專案

1. 進入本 GitHub Repository。
2. 找到副檔名為 `.ipynb` 的筆記本檔案。
3. 點擊檔案，查看程式碼、文字說明及已保存的執行結果。
4. 如需自行執行程式，可下載筆記本，或將檔案上傳至 Google Colab。
5. 依照筆記本中的說明執行程式，並觀察執行結果。

**注意事項：** Google Colab 的免費資源有使用限制，GPU 等運算資源不一定隨時可用，因此本專案所稱的「零成本」是指以免費資源為主要學習方式，不代表所有運算或相關服務都完全沒有費用。
